# Next.js dashboard UI starter

An earlier TypeScript UI project combining Next.js, Ant Design, Tailwind CSS and Chart.js. Built in 2022.

## Included

- A shared dashboard layout with navigation and a sidebar.
- Chart components using react-chartjs-2.
- Dashboard, ledger and notifications pages.
- A sample Next.js API route.

The repository contains a UI starter and examples, with its original Next.js 12 and React 18 dependencies.

## Run locally

```sh
yarn install --frozen-lockfile
yarn dev
```

Open http://localhost:3000. `yarn build` creates the production build and `yarn start` serves it. No automated test suite is defined.
